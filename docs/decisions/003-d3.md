# ADR-003: Use D3.js for supplementary charts

**Status**: Accepted

## Context

Beyond the 3D globe, obfina needs time-series charts (bandwidth over time), histograms (relay distribution by AS), and potentially choropleth map overlays. These require precise data-to-pixel mapping, geographic projections, and axis rendering that general-purpose animation libraries do not provide.

Candidates evaluated: D3.js, Chart.js, Recharts, Observable Plot.

## Decision

Use D3.js directly for supplementary data visualizations.

## Consequences

**Benefits:**

- D3 operates on the DOM directly rather than through a virtual layer, which matches Svelte's compilation model. A Svelte component can own a `<svg>` element and pass it to D3 without the DOM conflicts that occur in React.
- D3's geographic projection system (`d3-geo`) is the standard for map projections and integrates with TopoJSON country boundaries, which obfina uses for the choropleth overlay.
- D3 scales, axes, and color schemes are composable primitives that work independently — we use only what we need.

**Tradeoffs:**

- D3's API surface is large and its documentation is dense. Contributor onboarding for chart-related code takes more time than with a higher-level library like Chart.js.
- D3 transitions and Svelte transitions can conflict if both attempt to animate the same element. The convention in obfina is that D3 owns SVG elements entirely and Svelte handles HTML-layer transitions only.
- Observable Plot would have been a simpler API for most of the chart types obfina needs, but its geographic support is weaker than D3's.
